# InvestSync

Aplicativo para gestão de ordens de fundos com atualização em tempo real.

## 🛠️ Tecnologias
- C# (.NET 8) — API REST
- React + TypeScript — Frontend
- Material UI — Interface
- Apache Kafka — Mensageria
- Docker — Deploy local
- GitHub Projects — Planejamento
